# Evidencias de Fase II

## Nota de integridad académica
Las imágenes incluidas en `docs/capturas/` son **capturas visuales de referencia de la interfaz** preparadas para documentar la estructura de la solución. No deben presentarse como evidencia de una ejecución real si el estudiante no ha ejecutado el sistema en su propio entorno XAMPP.

Para la entrega final, después de ejecutar el proyecto localmente, se recomienda reemplazar o complementar estas imágenes con capturas reales que muestren:
- URL local del sistema.
- Fecha/hora visible cuando sea pertinente.
- Operación realizada.
- Resultado obtenido.
- Mensaje de validación cuando aplique.
